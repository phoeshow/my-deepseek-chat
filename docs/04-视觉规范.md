# 04 · 视觉规范

## 1. 设计基调

**极简三栏 · 灰阶为主 · 单一强调色 · 高信息密度**

- 界面本身要"退后"：中性灰阶承载结构，只有一个靛蓝强调色用于可分级的交互点
- 不用大圆角、不用渐变、不用毛玻璃、不用重阴影——层级靠**边框与背景明度差**建立
- 信息密度优先于留白（这是工具，不是落地页），但**消息正文的阅读舒适度优先于一切**

## 2. 布局栅格

```
┌──────────────┬────────────────────────────────────────┬────────────────┐
│  左栏 240px   │            中栏 flex:1                  │   右栏 280px    │
│ (200–320 拖拽)│                                        │ (240–360 拖拽)  │
├──────────────┼────────────────────────────────────────┼────────────────┤
│              │  顶栏 48px                              │  顶栏 48px      │
│  新会话 36px  │  标题 16/500 · 模型胶囊 · ⚙ · ＋        │  「参数」13/600 │
├──────────────┼────────────────────────────────────────┼────────────────┤
│  会话列表     │   ┌─────────────────────┐              │  控件区         │
│  36px/项      │   │ 用户消息（右对齐）    │              │                │
│  选中:       │   └─────────────────────┘              │  ───────────    │
│  accent-subtle│                                       │  状态区         │
│              │   ✦ 助手消息（全宽无气泡）              │  预算条         │
│              │   │▸ 已思考 2.1s                       │  缓存命中       │
│              │   │（思维链 13/1.6 次要色）            │  累计 token     │
│              │   正文 14/1.7 · max-width 760px 居中    │                │
│              ├────────────────────────────────────────┤                │
│              │  输入区 min 52 / max 200px             │                │
├──────────────┴────────────────────────────────────────┴────────────────┤
│  设置 36px（左栏底部固定）                                                │
└─────────────────────────────────────────────────────────────────────────┘
```

| 参数 | 值 |
|---|---|
| 最小窗口 | 960 × 640 |
| 默认窗口 | 1280 × 840 |
| 左栏 | 240px，可拖 200–320，可折叠至 0 |
| 右栏 | 280px，可拖 240–360，可折叠至 0 |
| 中栏正文 | **760px 居中**；代码块/表格可溢出到 100% 宽并横向滚动 |
| 顶栏高度 | 48px |
| 输入区 | 高 52px 起，随内容增至 200px 后内部滚动 |
| 内容左右内边距 | 24px |
| 消息间距 | 同一发言者内 8px，发言者切换 24px |

**折叠行为**：左栏折叠后中栏顶栏左侧出现 `☰`；右栏折叠后模型胶囊右侧出现滑杆图标。折叠状态与栏宽全部持久化到 `kv` 表。

**"回到底部"按钮**：距底部 > 300px 时浮现在输入区上方居中，28px 圆形，`surface` 底 + 边框。

## 4. 组件规范与状态

### 4.1 用户消息

- 右对齐，`--bubble-user` 底色，`--radius-md`，padding 10/14，`max-width: 70%`
- 字号 14/1.7，允许 Markdown（代码块带底但无工具条）
- 悬停显示「复制」；发送失败时气泡下方一行 `--danger` 文字 + 「重试」链接

### 4.2 助手消息

- **全宽无气泡**（阅读优先），左对齐
- 头部一行：`✦` 标记（16px，`--text-tertiary`）+ 模型短名（`--text-micro`，悬停才显）
- 正文 14/1.7，`max-width: 760px` 居中
- 悬停显示操作条：复制 / 重新生成（仅最后一条）
- 生成中：末尾 2px 宽 `--accent` 竖条光标，1s 呼吸（opacity 1↔0.2）
- 停止后：消息末尾右对齐 `已停止` 角标（11px，`--text-tertiary`）

### 4.3 思维链块（reasoning）

```
┌────────────────────────────────────────────┐
│ │ ▸ 已思考 2.1s                          │  ← 折叠态：micro 灰 + ▸
└────────────────────────────────────────────┘
┌────────────────────────────────────────────┐
│ │ ▾ 已思考 2.1s                          │
│ │ 用户问的是时间复杂度。先确认代码里是否 │  ← 展开态：13/1.6 次要色
│ │ 有嵌套循环……                           │
└────────────────────────────────────────────┘
```

| 属性 | 值 |
|---|---|
| 左竖线 | 2px，`--border-subtle`，通高 |
| 缩进 | 竖线后 12px |
| 正文 | 13 / 1.6 / 400，`--text-secondary` |
| 折叠头 | 11 / 1.3 / 500，`--text-tertiary`，可整行点击 |
| 生成中 | 折叠头文字变 `✳ 正在思考…`，文字上叠加 1.8s 微光扫过（`--text-tertiary` ↔ `--text-secondary`） |
| 默认状态 | **折叠** |
| 持久化 | 展开/折叠状态按消息记忆（仅本次运行） |

### 4.4 代码块

- 顶部工具条 32px：左侧语言标签（11px 大写，`--text-tertiary`），右侧复制按钮
- 工具条与代码区用 `--border-subtle` 分隔
- 代码区 padding 12/14，横向可滚动，圆角 `--radius-md`
- 复制后按钮变 `✓ 已复制` 1.5s
- 未闭合的流式代码块：正常渲染并保持滚动，不闪烁

### 4.5 参数面板（右栏）

| 控件 | 规格 |
|---|---|
| 分组标题 | 13 / 1.5 / 600，`--text-secondary`，下方 8px 间距 |
| 行标签 | 13 / `--text-secondary`，右侧显示当前值 `--text-primary` |
| 滑块 | 轨道 4px，拇指 14px，`--accent` 填充已选段 |
| 开关 | 32×18 胶囊，`--accent` / `--border` |
| 数值输入 | 宽度 64px，右对齐，失焦校验 |
| 分组间分隔 | 1px `--border-subtle`，上下 16px |

### 4.6 上下文预算条

```
上下文
12.4k / 1M
▓░░░░░░░░░░░░░░░  1.2%
```

- 进度条 3px 高，`--accent` → 超 80% 变 `--warn` → 超 95% 变 `--danger`
- 数字用 `--text-micro` + `tabular-nums`
- 悬停显示拆分：prompt / completion / reasoning / 缓存命中
- 红色状态只劝阻不阻止发送

### 4.7 会话项

| 状态 | 视觉 |
|---|---|
| 默认 | 13/1.5，`--text-primary`，单行截断，padding 8/10，圆角 6 |
| hover | `--surface-hover` 底 + 右侧显示 `⋯` |
| 选中 | `--accent-subtle` 底 + 左侧 2px `--accent` 竖条 |
| 生成中 | 右侧 6px 跳动圆点（`--accent`，0.9s 上下 2px） |
| 归档入口 | 列表底部固定，`--text-tertiary` |

### 4.8 空态

| 场景 | 内容 |
|---|---|
| 无 API Key | `--text-display` 标题「先配置 DeepSeek API Key」+ 副文案 + 主按钮「打开设置」 |
| 新会话 | 「今天想聊点什么？」+ 3 个示例提示词卡片（12px 灰边，hover 提亮，点击填入输入框） |
| 无会话 | 左栏显示「还没有对话」+ 居中「新建对话」按钮 |
| 离线 | 顶部细条 `--warn` 底，文案「离线模式：可浏览历史，发送将失败」 |

## 5. 动效

| 场景 | 时长 / 曲线 |
|---|---|
| hover / 选中 | 120ms `ease-out` |
| 面板折叠、分栏拖拽结束吸附 | 180ms `ease-out` |
| 消息入场 | 150ms `opacity 0→1` + `translateY(4px)→0` |
| 思维链展开 | 180ms 高度过渡（`grid-template-rows: 0fr → 1fr`） |
| 流式光标 | 1s `ease-in-out` 无限呼吸 |
| 思考微光 | 1.8s 线性往复 |

**禁止**：消息列表整体重排动画、逐 token 缩放、任何超过 250ms 的动画。

全部动效在 `@media (prefers-reduced-motion: reduce)` 下退化为无动画瞬时切换。

## 6. 键盘地图

| 快捷键 | 行为 |
|---|---|
| `Enter` | 发送 |
| `Shift+Enter` | 换行 |
| `⌘/Ctrl+N` | 新建会话 |
| `⌘/Ctrl+B` | 折叠/展开左栏 |
| `⌘/Ctrl+.` 或 `Esc` | 停止生成 |
| `⌘/Ctrl+R` | 重新生成最后一条 |
| `⌘/Ctrl+K` | 会话快速切换浮层 |
| `⌘/Ctrl+,` | 打开设置 |
| `↑`（输入框空时） | 编辑上一条用户消息（v1.1） |

**焦点管理**：新建会话后焦点进输入框；`Esc` 关闭弹层并把焦点还给触发元素；弹层内 `Tab` 循环不逃逸。

## 7. 无障碍

- 正文对比度 ≥ 4.5:1，大字号/图形 ≥ 3:1（明暗两套令牌都需验证）
- 焦点环统一 `2px --accent` + `2px offset`，**禁止** `outline: none`
- 流式区域 `aria-live="polite"`，但**只在生成结束时播报一次**完整文本（逐 token 播报会让读屏无法使用）
- 生成中按钮有 `aria-busy="true"`
- 所有图标按钮必须有 `aria-label`；纯装饰符号 `aria-hidden="true"`
- 动效尊重 `prefers-reduced-motion`

## 8. 图标

- 20px 线性图标，线宽 1.5px，`--text-secondary`，hover 转 `--text-primary`
- 使用集合：新建（+）、设置（齿轮）、发送（↑）、停止（■）、复制、重试（↻）、下拉（▾）、更多（⋯）、折叠（☰ / «）、回到底部（↓）、删除（垃圾桶）
- 助手身份标记 `✦` 作为纯文本字形使用，不做成图标组件

## 9. 文案规范

- 中文全角标点，英文/数字与中文之间留一个空格
- 按钮用动词短语：`新建对话`、`重新生成`、`导出 Markdown`
- 错误文案三段式：**发生了什么 + 为什么 + 怎么办**。例：「请求被限流（DeepSeek 每分钟请求数超限）。已自动重试 3 次仍未成功，请稍后再试。」
- 禁止在界面文案里出现 `Error`、`Exception`、堆栈信息（进日志）
