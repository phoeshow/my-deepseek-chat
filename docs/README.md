# my-deepseek-chat 设计文档

一个**本地运行**的 DeepSeek 桌面聊天助手。技术形态：Electron + React + TypeScript，数据全部留在本机。

> 状态：**设计基线 v1.0**（未开始编码）。文档中的结论已与产品 owner 逐项确认，实现阶段应以此为准；如需变更，先在本文的「决策记录」中登记。

## 场景一句话

> 你在本机打开一个窗口，输入问题，DeepSeek 的回答逐字出现——需要时能看到它怎么想的；关掉软件再打开，上一次的对话、模型选择、参数、思考开关都还在；所有内容不经过任何第三方服务器，只存在你自己的磁盘上。

## 设计原则

1. **本地优先**：除 DeepSeek API 请求外，无任何网络出口。无账号、无云同步、无遥测。
2. **Key 不出主进程**：渲染层永远拿不到明文 API Key。
3. **数据不怕断电**：任何一次生成中断，最多丢失 200ms 的输出。
4. **协议细节不写死**：模型名、上下文长度、能力全部运行时拉取，本地缓存兜底。
5. **为 v1.1 留结构，但不为它写代码**：树形会话、`usage_log`、`kv` 表在 v1 就建好，UI 先只露主线。

## 决策记录（Decision Log）

已确认的决策，实现阶段不再复议。变更须在此追加一行并注明触发原因。

| ID | 决策点 | 结论 | 核心理由 |
|---|---|---|---|
| ADR-01 | 应用形态 | Electron + React + TypeScript | 生态成熟、调试简单、Node 原生能力全开 |
| ADR-02 | 协议层 | OpenAI 兼容协议；v1 仅 DeepSeek，`base_url` 可配 | 复用 SDK 生态；改 base_url 即可接任意兼容服务 |
| ADR-03 | 请求发起位置 | 一律在主进程 | Key 不进 renderer；不受 CORS/CSP 限制；中止与重试集中 |
| ADR-04 | 流式实现 | `fetch` + `ReadableStream` 手解 SSE | `EventSource` 只支持 GET，无法用于 `/chat/completions` |
| ADR-05 | 会话结构 | 树形（`parent_id`）+ `active_leaf_id`；v1 只展示主线 | v1 表现为线性；将来加"编辑即分叉"零迁移 |
| ADR-06 | 上下文策略 | 全量发送 + 预算可视化 | V4 为 1M 窗口且前缀缓存便宜；实现最简、质量最好 |
| ADR-07 | `reasoning_content` | 必须落库 | 带 `tools` 时后续轮次必须回传，否则 API 返回 400 |
| ADR-08 | 思考模式开关 | 三级：全局默认 → 会话覆盖 → 本条临时 | 写代码与写周报需求不同，只有全局开关不够用 |
| ADR-09 | 密钥存储 | `safeStorage` 加密后存 `userData/secret.json`；不进 renderer | 零额外依赖，跨三平台走系统密钥链 |
| ADR-10 | SQLite 驱动 | `better-sqlite3` | 同步 API、性能最好、事实标准；接受原生模块重建成本 |
| ADR-11 | 消息写入策略 | 先插入空 assistant 消息，流式中每 200ms 增量 flush | 崩溃/断电最多丢 200ms 输出 |
| ADR-12 | 导出 | 纳入 v1 | 几十行代码，却能救回全部历史 |
| ADR-13 | 视觉 | 极简三栏（240 / 1fr / 280），灰阶 + 靛蓝，正文 760px 居中 | 高信息密度、阅读舒适、专注度好 |
| ADR-14 | 输入键位 | `Enter` 发送 / `Shift+Enter` 换行 | 聊天软件通行习惯 |
| ADR-15 | 默认主题 | 跟随系统，可锁定亮/暗 | 桌面应用标准行为 |
| ADR-16 | 输入区布局 | 占满中栏宽度、最小两行高、独立成带（`bg-canvas` + 顶部实线），控件行在输入框之外右对齐 | 高度即"可多行"的暗示；与对话区明确分层，避免两条边线打架 |
| ADR-17 | 深度思考默认值 | **默认开启**（switch 形态）；老配置由 `config.version` 1→2 一次性迁移 | 应用卖点是"看得见推理"；用户可逐层关闭。代价是默认消耗 reasoning tokens |
| ADR-18 | 发送键呈现 | 文案 `Enter`（等宽 semibold）+ 4px 扩散光晕 + `active: scale(0.9)` | 用键位本身代替抽象箭头，降低"按哪里"的认知成本 |
| ADR-19 | 图标体系 | 统一 Font Awesome Free Solid，集中在 `icons.ts` 登记；禁止自绘 SVG 与字符图标 | 跨主题/DPI 一致，字符图标会随字体回退漂移；体积代价 +158KB 可接受 |
| ADR-20 | 参数面板默认状态 | **每次启动收起**，展开状态不写入配置（宽度仍持久化） | 参数是可选内容，默认占 280px 会挤掉对话区；"记住上次展开"等于让次要面板长期侵占主区域 |
| ADR-21 | 搜索入口与形态 | 左栏顶部常驻搜索框；结果**就地替换左栏列表**；`⌘K` 聚焦该框，取消独立的快速切换浮层 | 入口与结果同处一侧，视线不需要来回跳；全项目只留一套搜索，避免两套召回逻辑 |
| ADR-22 | 用量仪表盘 | 中栏独立视图 + 左栏底部入口；只统计 tokens/缓存/延迟，**不显示费用**；图表用 CSS 手写 | 数据是事实，费用依赖会变的价格表；7 根柱子不值得引入图表库 |

## 术语表

| 术语 | 含义 |
|---|---|
| **会话（session）** | 一棵消息树 + 该会话的模型/参数设定 |
| **主线（mainline）** | 从 `active_leaf_id` 沿 `parent_id` 回溯得到的消息序列，即 v1 界面上看到的内容 |
| **思考内容（reasoning）** | DeepSeek 思考模式返回的思维链，流式字段为 `reasoning_content` |
| **前缀缓存（cache hit）** | DeepSeek 上下文硬盘缓存。命中部分的输入 token 价格显著低于未命中部分 |
| **帧（frame）** | 主进程把 SSE 解析结果归一化后推给渲染层的内部消息单元，见 02 §4 |
| **三级开关** | 思考模式的生效优先级：本条临时 > 会话设定 > 全局默认 |
