## 核心设计取向

- **本地优先**：除 DeepSeek API 外无任何网络出口，无账号、无遥测
- **Key 不出主进程**：渲染层永远拿不到明文 Key
- **中断不丢数据**：流式期间每 200ms 落库，最坏丢 200ms 输出
- **协议不写死**：模型名与能力运行时 `GET /models` 拉取，本地缓存兜底
- **树形会话**：v1 只露主线，为将来的消息编辑与版本切换留零迁移路径
